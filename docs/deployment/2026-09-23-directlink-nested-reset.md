## 用户操作说明

- 禁用后使用“恢复”，继续使用原凭据。
- 撤销后旧凭据永久作废，使用“重置 Token”生成新凭据，完整值只显示一次。
- “重置次数”只清零累计已用次数，不重新生成凭据，不恢复撤销/过期状态。
- 重置 Token 保留原过期时间；已过期记录需再编辑有效期。
- 每文件实际尝试计一次，失败也计；预览、未找到文件、额度不足未尝试不计。
- UI 等待完整批次后显示所有结果及各自复制按钮，不宣称实时逐文件渲染。
