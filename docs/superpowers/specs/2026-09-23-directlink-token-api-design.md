# 独立直链 API 与 Token 管理设计

状态：待用户审阅书面规格；口头功能与部署方向已经确认。
基线：上游 v2.2.4，提交 1806869。Fork 保留 main 跟踪上游，定制工作在 feat/directlink-token-api。

## 1. 目标与边界

在现有百度网盘网页左侧菜单底部（系统设置之后）加入「API Token」，桌面和移动导航均有入口。在现有「分享直下」对话框中增加「提取直链」按钮，展示各文件链接、下载所需请求头和复制按钮。原有下载功能保持原样。

独立 API 接受百度个人分享链接、提取码和选中文件，将文件转存到当前账号的专用目录，再返回直链；不创建服务器下载任务，不下载文件内容到服务器。用户已允许临时转存占用百度网盘空间。第一版不承诺企业分享、无限速、永久直链，不涉及计费、套餐或公开注册。

HTTP 与 HTTPS 均可使用，不跳转；后台显著提示 HTTP 明文风险。不得因此撤掉管理员鉴权、跨站防护或把 Rust 原始接口直接开放给 Token 用户。百度登录凭据、管理员密码、API Token 为三套不同凭据。

## 2. 架构和上游更新

- 原 backend 不承担 Token 管理；新增独立 Rust sidecar（directlink-api/），自己的 SQLite、配置及 systemd unit，仅监听回环地址。
- Nginx 将 /direct-api/ 和 /direct-admin/ 转发到 sidecar，其余请求仍转发原 Rust；保留 HTTP /ws 原有转发、HTTPS、其他站点和 9701 后台。
- Vue 只增加 Token 页面、API 客户端、复制工具、菜单/路由和分享对话框入口。sidecar 不嵌入上游 Rust 内部模块。
- sidecar 通过回环 HTTP 调用上游接口；底层 URL 由部署配置固定，调用者不能指定服务器地址、账号 Cookie、任意网盘目标或本地文件路径。
- main 同步上游；功能分支合并经过测试的上游版本。每次更新跑兼容测试再部署，不自动覆盖线上，也不承诺零冲突。
- 如果现有 HTTP 接口无法安全满足账号绑定/临时目录限定，必须先报告并形成小范围兼容补丁，不通过全局切换账号绕过隔离。

## 3. 管理入口与鉴权边界

- 管理页路由 /api-tokens，网页管理员认证后使用。前端路由不是安全边界。
- /direct-admin/v1/* 仅接受管理员代理通道：Nginx 使用现有 htpasswd 验证 Basic 凭据，覆盖注入独立高熵管理通道密钥；sidecar 恒定时间校验。拒绝未设置/空密钥启动，密钥来自受限配置文件而非提交到仓库。
- 管理请求不接受 API Bearer Token 替代管理员认证。外部伪造的管理通道头由 Nginx 无条件覆盖；public location 清空该头。sidecar 端口不能公网暴露。
- 修改操作仅允许 JSON，校验同站 Origin 与 Fetch Metadata，跨站拒绝。浏览器路径使用管理员通道，不保存长期 API Token 到 localStorage。
- 管理请求通过独立 axios 实例发送，避免现有百度/Web 登录拦截器注入 Bearer 干扰 Basic 认证。
- API 路径只接受 Authorization: Bearer，不接受 URL 查询 Token、Basic 密码或 Cookie 替代。CORS 默认关闭，不使用通配允许来源。

## 4. Token 生命周期与 SQLite

Token 为 dl_ 前缀加操作系统 CSPRNG 32 字节的 base64url 编码。只在创建响应中返回一次；SQLite 保存 SHA-256 摘要和独立记录 ID、显示标识，不存完整 Token。随机 Token 高熵，不等同于低熵密码哈希。

字段：id、name、note、display_prefix、secret_hash、enabled、revoked_at、expires_at、created_at、updated_at、last_used_at、rate_per_minute、success_count、failure_count。

- 名称 1–80 字，备注最多 500 字；有效期为空才表示永久。UTC 时间戳存储，网页以本地日期和具体时分显示，已到期立即标「已过期」。
- 默认每分钟 10 次提取创建请求；允许管理员设 1–60。列表预览/任务查询另设每分钟 60 次读取上限。
- 支持创建、分页查询、修改名称/备注/期限/限频、禁用/恢复、永久撤销。撤销记录保留统计且不可恢复；无 Token 明文找回接口。
- 更新和校验用 SQLite 事务；禁用/过期/撤销每次请求生效，不依赖长期缓存。永久撤销后不得靠修改 enabled 恢复。
- 最近使用记录通过有效 Token 鉴权的请求；成功/失败次数按提取任务最终结果计一次，无效 Token 请求不归属到任意记录。日志只记录 Token ID 和错误码。
- SQLite 开 WAL/busy_timeout；数据目录 0700、DB 和配置 0600；迁移及备份考虑 WAL。额度/任务状态跨进程重启保留，限流不因重启直接清零。

## 5. 独立 API 合约

所有响应为 JSON，包含明确业务 code/message；不把上游原始响应、Cookie、内部 URL 或带签名的直链放进错误日志。

- POST /direct-api/v1/shares/preview：share_url、password（可选），返回临时 preview_id 与有限文件列表；目录按需分页展开，不隐式无限递归。
- POST /direct-api/v1/resolve：share_url、password（可选）、selected_fs_ids（可选）；返回 HTTP 202 和 job_id。若未指定文件，只允许数量/体积在限制内的根目录普通文件，不隐式转存整个目录。
- GET /direct-api/v1/jobs/{id}：仅创建者 Token 可访问，返回 pending/running/succeeded/failed；成功返回 filename、size、url、headers，未知直链期限返回 null，不虚构永久或固定有效期。
- 管理网页使用 /direct-admin/v1/shares/preview、/resolve 和 /jobs/{id} 的同构接口，不需要生成 API Token。
- POST/GET /direct-admin/v1/tokens 创建/分页列表；PATCH /tokens/{id} 修改与禁用/恢复；POST /tokens/{id}/revoke 永久撤销。

错误：缺失/错误/撤销 Token 401；禁用、到期 403；其他 Token 任务返回 404 防枚举；超频 429 并带 Retry-After；输入错误 400；超过已知数量/空间预算 422；底层账号未登录或服务不可用 503；任务级上游失败返回可区分的失败状态。错误提取码与服务故障分开提示。

请求体上限 16 KiB；仅接受解析后的 HTTPS pan.baidu.com 分享链接，不允许任意域名、用户信息、非标准端口、内网地址或由调用者控制的上游 URL。只从明确字段获取提取码，不记录原始分享链接查询串。

## 6. 转存流程、账号与限额

已查证：v2.2.4 的 is_share_direct_download=true 强制自动下载；sidecar 禁止使用这个模式。普通转存必须显式 auto_download=false。

1. 校验 Token、输入、限流、全局并发预算，创建持久化任务与账号绑定。
2. 预览并核实选中文件，禁止仅相信客户端提供的大小/名称/fs_id。
3. 第一版单账号固定绑定：必须验证底层处于配置的账号；检测多账号切换/账号不一致时拒绝工作。取直链能力需验证并发切换场景；若无法消除竞态，增加上游显式账号参数的小补丁并重新审阅，不能默认认为前后各检查一次已足够安全。
4. 生成独立目录 /.bpr_directlink_api/{job_uuid}/，普通转存且 auto_download=false，轮询任务到最终状态；仅允许操作该任务登记的目录。
5. 根据实际转存结果取得目标文件路径与 ID，再调用现有取链接接口；不得直接接受外部传入的网盘路径。
6. 获取所需下载 UA/请求头并验证是否需要用户 Cookie；如果直链依赖账号 Cookie，绝不能把 Cookie 返回调用者，应判定现路线不满足“独立直链”并报告。
7. 返回结果，不启动本地下载器。

默认全局并发 1；单任务最多 20 个普通文件，单任务总大小 2 GiB；专用目录已登记保留文件与在途任务的空间预算共 10 GiB。预算预留原子执行，错误不提前释放可能已经落盘的空间；不以磁盘字节冒充下载流量。这些限额可由管理员配置，第一版不按 Token 计下载带宽。

任务等待最多 180 秒。超时/取消不能保证已停止百度侧任务，必须进入待核对状态，不立刻删除还在使用的目录或释放额度。重启恢复核对在途任务，不能盲目重放转存。

## 7. 临时文件与数据保留

第一版不在取得直链后自动删除文件，不做未验证的定时删除。管理页展示专用任务占用与管理员手动清理入口，清理前提示可能令已发出的链接失效；只清理已终止、无在途操作且账号匹配的登记目录，拒绝用户自定义路径。

保留任务与审计元数据；直链结果因本身属于敏感下载凭据，只存受限 SQLite，24 小时后清空 url/headers（不声称链接恰好有效 24 小时），请求日志不记录响应体。文件保留到管理员主动清理或后续经过实测批准的回收策略启用。达到预算停止新提取并提示清理，不擅自删除其他文件。

## 8. 网页交互

Token 页面为紧凑表格：名称/备注、标识、状态、有效期（含时分）、最近使用、成功/失败次数、操作；创建弹框设置名称、备注、有效期、限频。创建成功单独展示完整 Token，可复制并明确提示仅显示一次；撤销需要二次确认。

分享对话框保持原按钮，新增「提取直链」；选择文件后仅提取选中项，进行中阻止重复提交。结果弹框逐文件显示链接与所需请求头，支持逐项复制和复制全部；失败清楚展示提取码错误、未登录、超限、底层错误，不展示空的成功弹框。

HTTP 下优先尝试可用剪贴板接口，回退到用户点击触发的选中文本复制；失败显示可选中文本与手动复制提示，不虚报复制成功。组件销毁停止轮询，Token 明文弹框关闭时从组件状态清除。

- 前端：创建/禁用/撤销、已过期样式、时区转换、复制成功/回退/失败、选择文件不丢失、请求失败状态、菜单与移动导航。
- 兼容实测：用用户提供的可测试小分享与已登录账号完成预览→临时转存→取直链→在另一客户端有限字节 Range 验证；不下载大文件，不用随机第三方分享。没有真实测试素材时明确未验证，不能宣称端到端完成。
- 安全回归：HTTP/HTTPS 后台匿名 401、管理认证有效；Bearer 不能进管理页；伪造头不能进入管理员 API；非同站来源 403；sidecar/原 backend 回环监听；/health 不重新开放；旧 /ws 和 9701 不变。
