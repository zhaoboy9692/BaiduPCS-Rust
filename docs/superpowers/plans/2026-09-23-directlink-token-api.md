# Directlink Token API 实施计划（按用户最新范围修订）

用户确认：只包装现有 API；账号、转存、任务管理沿用 BaiduPCS-Rust。不做 uid 补丁、账号切换逻辑、第二套任务/清理/空间预留系统。

- [x] 独立 SQLite Token 管理、管理员通道、Token 页面和专项 CI。
- [x] 固定回环 upstream 客户端；严格分享 URL、有限文件列表和安全响应字段。
- [x] TDD：预览 → 显式创建并验证目标目录 → 普通转存 auto_download=false → 轮询原任务 → 列出转存文件 → 原取直链接口。有限同步等待；超时提示在原任务页查看，不重放任务。
- [x] Bearer 公共 API 与管理员同构 API，限流与成功/失败统计，单并发防重复资源消耗。
- [x] 现有分享弹窗加提取按钮及结果弹窗、复制功能，保留原下载路径。
- [x] 文档与 nginx/systemd 示例，专项测试、构建和自查。
- [x] 部署到授权服务器，保留 HTTP/HTTPS 和原有服务；检查服务、鉴权、预览及独立直链 Range 下载。
- [ ] 其他账号的小文件分享端到端验收（原转存接口自分享回存失败；清理测试文件时原接口又报告账号凭证不完整）。恢复账号登录后继续，不能宣称完整链路已通过。

第一版仅支持分享根目录普通文件；每次至多20项/2GiB。目录或超量明确报错，不隐式大量转存。转存到 UUID 专用目录并保留，管理员使用原文件页手动清理。直链不持久化，期限未知返回 null；不返回百度 Cookie 或预览凭据。

验证与部署详情见 `docs/deployment/2026-09-23-directlink-api.md`。
