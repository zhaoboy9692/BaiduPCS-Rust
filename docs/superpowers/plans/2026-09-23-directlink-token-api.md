# Directlink Token API 实施计划（按用户最新范围修订）

用户确认：只包装现有 API；账号、转存、任务管理沿用 BaiduPCS-Rust。不做 uid 补丁、账号切换逻辑、第二套任务/清理/空间预留系统。

- [x] 独立 SQLite Token 管理、管理员通道、Token 页面和专项 CI（前一提交）。
- [ ] 固定回环 upstream 客户端；严格分享 URL、有限文件列表和安全响应字段。
- [ ] TDD：预览 → 普通转存 auto_download=false → 轮询原任务 → 列出转存文件 → 原取直链接口。有限同步等待；超时提示在原任务页查看，不重放任务。
- [ ] Bearer 公共 API 与管理员同构 API，限流与成功/失败统计，单并发防重复资源消耗。
- [ ] 现有分享弹窗加提取按钮及结果弹窗、复制功能，保留原下载路径。
- [ ] 文档与 nginx/systemd 示例，专项测试、构建和自查。
- [ ] 用户授权的小分享 + 已登录账号实测外部 Range 下载；未实测不得宣称上线可用。

第一版仅支持分享根目录普通文件；每次至多20项/2GiB。目录或超量明确报错，不隐式大量转存。转存到 UUID 专用目录并保留，管理员使用原文件页手动清理。直链不持久化，期限未知返回 null；不返回百度 Cookie 或预览凭据。

已有基线：Rust 12 测试、前端新增9测试通过；上游全量前端 FilesView 搜索断言有一个已知失败。线上尚未部署 sidecar。
